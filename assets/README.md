# Arte promocional

`header.png` é uma ilustração original criada para o README de **PLUTONITA: WORLD DOMINATION**. Representa um executivo de goma, uma fábrica ambulante e expansão mundial; não é uma captura da interface do jogo.

- Ferramenta: geração de imagens integrada (`image_gen`), sem uso de CLI/API externa.
- Arquivo utilizado pelo projeto: `assets/header.png`.
- Direção visual: terminal corporativo de 1998, preto carvão, verde ácido, roxo, textura de impressão e humor empresarial surreal.
- Nenhum logotipo da Arcor, embalagem comercial ou mascote proprietário foi utilizado como referência.

## Prompt de geração

```text
Use case: ads-marketing. Create one original wide landscape README header banner for an independent Brazilian terminal strategy game. Aspect ratio 3:1, ideally 1536x512 or 1920x640. It should feel like beautifully art-directed 1998 Brazilian indie game box art crossed with a radioactive corporate computer terminal. Deep charcoal black backdrop, acid lime green main color, purple accents and tiny warm amber details, clean bold screenprinted illustration with delicate CRT scanlines and halftone texture.

Exact title text, large and extremely legible: "PLUTONITA"
Directly below in smaller wide-spaced capitals: "WORLD DOMINATION"
No other text. Original lettering, not a recreation of any commercial candy logo.

Composition: Large title occupies the center-left half with generous dark space around it, absolutely no cropping of lettering. At the far right a mischievous lime-green anthropomorphic bubble-gum blob in a neat dark business suit holds a small briefcase; behind it an old Brazilian factory has developed absurd long walking legs and is stepping over a wireframe globe. Small purple gum bubbles float above the factory. A faint terminal grid and subtle stock-chart steps suggest worldwide expansion. Everything coherent, playful, surreal and professionally composed, not crowded. This is promotional illustration, NOT a screenshot of game graphics. The absurd character must feel like a serious corporate executive. Crisp readable silhouettes at GitHub README size.

Constraints: no Arcor logos, no proprietary packaging or copied mascots, no watermarks, no real product logos, no extra slogans or fake buttons. Entire artwork original. Opaque dark background.
```
